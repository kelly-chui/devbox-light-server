# Implement Feature

1. Read `tasks/README.md` and the relevant task card.
2. Read `AGENTS.md` and inspect the existing implementation.
3. Define the smallest reasonable scope.
4. Create an implementation plan that includes:
   - files to create
   - files to modify
   - behavior changes
   - tests to add or update
   - tradeoffs or assumptions
5. Implement work that is within the task card's scope.
6. Ask for direction only when the work would materially exceed the task card, require a significant new design decision, or cause an external side effect.
7. Run the relevant tests.
8. Update the task card's checkpoints, tests, details, and related commits.
9. Summarize:
   - what changed
   - error handling or limitations
   - tests run
   - tests not run
