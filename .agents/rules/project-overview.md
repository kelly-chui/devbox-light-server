# Project Overview

This project is a lightweight development server for app development and local testing.

The project is closer to a mock server than a production backend.

## Technology

- TypeScript
- Express
- Vitest

## Goals

- Keep the codebase easy to understand.
- Prefer simplicity over production-grade complexity.
- Avoid introducing infrastructure that is unnecessary for a lightweight development server.
