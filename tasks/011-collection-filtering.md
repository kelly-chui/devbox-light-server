## 2. 체크포인트

- [x] 인메모리 레코드 저장소에 필터링을 구현한다.
- [x] JSON 레코드 저장소에 같은 필터링을 구현한다.
- [x] HTTP query parameter를 필터로 전달한다.
- [x] 필터링 동작을 단위·통합 테스트로 검증한다.

## 3. 테스트

- 목록 필터링, 인메모리·JSON 저장소 일관성, HTTP query parameter 처리
