# 006 인증과 JSON 영속성

## 1. 목표

토큰 인증을 구현하고, 인증·레코드·파일 저장소를 JSON 파일에 유지하며 memory/json 실행 모드를 선택할 수 있게 한다.

## 2. 체크포인트

- [x] 토큰 저장소 계약과 인메모리 구현을 추가한다.
- [x] 로그인·로그아웃·현재 사용자 HTTP API를 구현한다.
- [x] 인증과 레코드 저장소의 JSON 파일 구현을 추가한다.
- [x] 파일 저장소가 디스크에 유지되도록 구성한다.
- [x] `PERSISTENCE` 설정으로 memory/json 모드를 선택하게 한다.
- [x] 인증·영속성·실행 모드 동작을 테스트한다.

## 3. 테스트

- 로그인·로그아웃·현재 사용자, JSON 저장소 읽기·쓰기, memory/json 실행 모드

## 4. 세부사항

- 토큰 서비스·저장소·HTTP API
- JSON 기반 token·record 저장소와 공용 파일 유틸리티
- `PERSISTENCE` 실행 모드와 관련 테스트
