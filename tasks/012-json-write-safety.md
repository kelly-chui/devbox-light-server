# 012 JSON 저장소 동시 쓰기 안전성

## 1. 목표

동시에 일어나는 JSON 기반 저장소 쓰기를 직렬화해 데이터가 서로 덮어써지는 문제를 막는다.

## 2. 체크포인트

- [x] 같은 JSON 파일에 대한 쓰기 작업을 순서대로 실행한다.
- [x] token 저장소가 공용 직렬화 로직을 사용한다.
- [x] record 저장소가 공용 직렬화 로직을 사용한다.
- [x] 동시 쓰기에서 데이터가 보존되는지 테스트한다.

## 3. 테스트

- token·record 저장소의 동시 JSON 파일 쓰기와 데이터 보존

## 4. 세부사항

- 공용 JSON 파일 쓰기 직렬화
- token·record 저장소 변경과 동시 쓰기 테스트
