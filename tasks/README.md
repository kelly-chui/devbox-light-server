# DevBox 작업 목록

이 디렉터리는 DevBox의 작업 원본이다. 하나의 작업은 **독립 PR로 설명·검토·병합할 수 있는 결과물 하나**를 뜻한다. 작은 코드 변경이나 커밋 하나가 작업 하나여야 하는 것은 아니다.

## 상태

- `예정`: 아직 시작하지 않은 작업
- `진행 중`: 구현 또는 검증 중인 작업
- `차단됨`: 외부 결정이나 선행 작업을 기다리는 작업
- `완료`: 체크포인트와 검증을 마친 작업
- `대체됨`: 결과가 이후 변경으로 제거되거나 대체된 역사 작업

## 운영 규칙

1. 새 작업은 `TEMPLATE.md`를 복사해 세 자리 다음 번호로 만든다. 사용한 ID는 재사용하지 않는다.
2. 구현 전에 목표·체크포인트를 적고, 완료 시 테스트한 내용을 갱신한다.
3. 작업이 독립 PR로 설명되지 않으면 더 나누거나 상위 작업으로 바꾼다.
4. 완료 시 실제 검증 명령과 결과를 작업 파일에 남기고, 이 표의 상태도 함께 갱신한다.
